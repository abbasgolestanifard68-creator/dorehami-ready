# دورهمی — نسخه نمایشی 0.7.0+7

این بسته ادامه افزایشی نسخه ۰٫۵ است. بخش‌ها و تصمیم‌های قبلی حفظ شده‌اند.

## افزوده‌های نسخه ۰٫۷
- جایگاه نمایشی تبلیغ برند در صفحه نقشه/خانه.
- بخش مستقل «تبلیغات برندها» در پنل مدیریت، جدا از لینک‌های اختصاصی جذب کاربران؛ امکان افزودن کمپین نمونه و فعال/غیرفعال‌کردن آن.
- بخش «به‌روزرسانی اپلیکیشن» در پروفایل برای نمایش مسیر بررسی نسخه جدید.
- آماده‌سازی مستندات فنی لازم برای اتصال سامانه تبلیغات برندها و انتشار/به‌روزرسانی نسخه‌ها.
- ساختار Android به پروژه Flutter اضافه شده است.

## محدودیت‌های مهم
این نسخه همچنان نمونه نمایشی است و داده‌ها در حافظه برنامه نگهداری می‌شوند. بررسی و نصب نسخه جدید هنوز به سرور انتشار متصل نیست. تبلیغات برندها، آمار بازدید/کلیک و پنل مدیریت نیز هنوز به سرور وصل نشده‌اند و آمار فعلی نمونه‌اند.

برای به‌روزرسانی خارج از فروشگاه، اندروید معمولاً تأیید کاربر و اجازه نصب برنامه از منبع مربوط را لازم دارد؛ بنابراین «خودکار» می‌تواند به معنی تشخیص و دریافت خودکار نسخه جدید و هدایت کاربر به نصب باشد، نه نصب بی‌صدای تضمین‌شده در یک اپلیکیشن عادی. اگر انتشار از فروشگاهی با API به‌روزرسانی درون‌برنامه‌ای انجام شود، مسیر اختصاصی همان فروشگاه قابل استفاده است.

## اجرا و ساخت
1. Flutter SDK، Android SDK و JDK سازگار را نصب کنید.
2. در ریشه پروژه اجرا کنید: `flutter doctor`
3. سپس: `flutter pub get`
4. بررسی کد: `flutter analyze`
5. تست‌ها: `flutter test`
6. ساخت APK آزمایشی: `flutter build apk --debug`
7. ساخت APK انتشار: `flutter build apk --release`
